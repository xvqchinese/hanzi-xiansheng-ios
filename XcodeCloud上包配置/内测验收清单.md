# 汉字先生 iOS V2.0 懒加载修复 — TestFlight 内测验收清单

> 验收目标（本次修复范围，仅三项）：
> ① App 启动不再卡死（原问题：一次性全量加载字库 → 内存溢出 → iPhone/iPad 启动卡死）
> ② 笔母字形渲染正常、无方框 □
> ③ 键盘输入功能正常
>
> 原则：只验证「修复没破坏原有功能 + OOM 已消除」，不验收任何新功能（本次没有新增功能）。

---

## 一、测试环境准备

| 项 | 要求 |
|---|---|
| 测试包来源 | TestFlight 安装（内部测试组），Build 号记录于此：______ |
| 设备 1（低配优先） | 内存最小的旧 iPhone（如 iPhone 8 / SE2 / XR），iOS 15–16 |
| 设备 2 | 日常主力 iPhone，iOS 17/18 |
| 设备 3 | 任意 iPad（原问题明确提到 iPad 卡死） |
| 对照 | 如条件允许，保留一台装旧版（修复前）做对比 |
| 网络 | 至少一次完整流程在 Wi-Fi 下、一次在蜂窝网络下 |

## 二、启动卡死验收（核心 ①）

| # | 步骤 | 通过标准 | 结果 |
|---|---|---|---|
| 1.1 | 杀进程后冷启动 App，计时 | 从点图标到主界面可交互 ≤ 3 秒（旧机 ≤ 5 秒），**无白屏定住、无自动闪退** | ☐ |
| 1.2 | 连续冷启动 10 次 | 10/10 全部成功，无一次卡死或闪退 | ☐ |
| 1.3 | 首次安装后立即启动 | 首次启动（无任何缓存分片）同样不卡死 | ☐ |
| 1.4 | 系统设置 → 通用 → 键盘 → 添加「汉字先生」键盘，然后回到 App 冷启动 | 添加键盘后 App 启动仍正常 | ☐ |
| 1.5 | 在任意 App（备忘录/微信）调出汉字先生键盘 | 键盘 **2 秒内弹出**，不出现「键盘加载中」转圈卡死 | ☐ |
| 1.6 | 反复切换键盘（地球键）20 次 | 键盘扩展无闪退、无消失、无卡在选择器 | ☐ |
| 1.7 | 设备剩余存储 < 1GB 状态下冷启动 + 调键盘 | 不卡死（低存储下原子写/分片读取仍正常） | ☐ |
| 1.8 | 锁屏静置 10 分钟后解锁直接调键盘 | 键盘进程被系统回收后重新拉起正常 | ☐ |

> 判定红线：任何一台设备出现一次「启动定住 > 10 秒」或「启动闪退」= 不通过，回炉。

## 三、笔母字形渲染验收（核心 ②）

| # | 步骤 | 通过标准 | 结果 |
|---|---|---|---|
| 2.1 | 键盘输入一个笔母码（如 PN），查看候选栏 | 候选字的**笔母字形**（D/H/S/P/N/Z 折体字形）正常显示，**无方框 □、无问号、无空白** | ☐ |
| 2.2 | 输入含调母的完整码（如 PN+ren → 人） | 带调母标记的字形（阳平 x / 上声 v / 去声 q 附加记号）正常显示 | ☐ |
| 2.3 | 覆盖 6 笔母各打至少 1 个字 | 点 D / 横提 H / 竖竖钩 S / 撇 P / 捺 N / 折 Z 六类字形均渲染正常 | ☐ |
| 2.4 | 打调母三字母 x / v / q 各一次 | 调母记号字形（E020–E022 码位）正常，无方框 | ☐ |
| 2.5 | 主 App 内打开字库查询/字典页（原有功能） | App 内字形同样无方框（主 App 与键盘是两个进程，需分别验证字体注册） | ☐ |
| 2.6 | 打扩展区生僻字（如扩展B区 𠅤） | 字形正常或按原逻辑降级，**不出现整片方框** | ☐ |
| 2.7 | 快速连续输入 5 分钟（高频触发分片换入换出） | 全程无方框复现（NSCache 淘汰后重载正常） | ☐ |
| 2.8 | 键盘弹起后立刻打字（字体注册竞态） | 第一次击键的候选即无方框 | ☐ |

> 判定红线：任何位置出现一个 □ = 不通过（说明键盘扩展进程字体注册失效，回查 KeyboardViewController init 内 MyTokenFont.registerIfNeeded() 位置）。
